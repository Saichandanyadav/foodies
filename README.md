# foodies. | Exquisite Royal Indian Restaurant

A premium, highly interactive regional Indian culinary showcase platform. This web application delivers an immersive digital experience reflecting ancient stepwells, imperial courts, and legendary royal kitchens. Engineered with modern optimization architectures to guarantee ultra-fast performance across all viewport layouts.

**Live Demo:** [https://foodietable.vercel.app/](https://foodietable.vercel.app/)

---

## 🚀 Key Architectural Upgrades

### 1. Synchronized Dual-Action Topbar UI

* **Contextual Mobile Layouts:** Embedded localized `Book a Table` injection elements targeting high-intent conversions directly within the primary viewport header row for small devices ($< 640\text{px}$).
* **Layout Safety Filters:** Sanitized multi-attribute JSX token conflicts to enforce strict compliance with ESLint rules (`react/jsx-no-duplicate-props`).

### 2. Full-Screen Right-Side Drawer Navigation

* **Side-Drawer Architecture:** Replaced low-fidelity drop-down frames with an immersive, fluid slide-out drawer executing on the screen's right boundary.
* **Layer Stability:** Fixed mobile background dynamic bleed-through using explicit white layer surfaces (`bg-white`) combined with back-dropped frosted overlay masks (`bg-brand-dark/40 backdrop-blur-sm`).

### 3. Deep Content Pillar Expansion

* **Extended Structural Messaging:** Upgraded the primary layout view from single-fold sections to include functional foundation segments outlining hand-pounded spice techniques, ancestral chef lineages, and organic A2 cow ghee sourcing models.
* **Immersive Ambience Overviews:** Integrated rich secondary grid spaces to highlight fine-dining atmosphere signatures, stepwell interior properties, and live musical instrumentation setups.

### 4. Global Footprint Brand Verification Badge

* **Static Corner Anchor:** Deployed a global high-index layout layer fixed securely at the bottom right corner of all viewport spaces (`fixed bottom-6 right-6 z-[100]`).
* **Micro-Interactions:** Custom animated pulsing alert vectors combined with rotational transformations (`group-hover:rotate-12`) identifying the production build context: **Demo Showcase by Growth Craft by Sai**.

## 🛠️ Stack Architecture

* **Framework:** Next.js (App Router, Client/Server Component splitting optimized via `'use client'`)
* **Styling:** Tailwind CSS (Fluid utility layers, responsive layout grids, custom variable theme values)
* **Icon Suite:** Lucide React (Optimized, vector-scalable asset references)
* **Deployment Engine:** Vercel Production Network

## 📦 System Installation & Execution

To run this platform locally within a development environment, execute the following terminal operations:

```bash
# 1. Clone the master repository branch
git clone https://github.com/your-username/foodies-restaurant.git

# 2. Enter into the platform runtime directory
cd foodies-restaurant

# 3. Provision local package dependencies
npm install

# 4. Trigger the local development engine
npm run dev

```

Open [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) inside your web browser environment to verify the active workspace.
